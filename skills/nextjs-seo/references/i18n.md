# i18n: hreflang and localized SEO

Use only when the site serves multiple locales (usually an `app/[lang]/` segment).

## Per-page alternates helper

```ts
// lib/i18n/alternates.ts
import type { Metadata } from "next";
import { locales, defaultLocale, type Locale } from "./config";

export function localeAlternates(lang: Locale, path: string): Metadata["alternates"] {
  return {
    canonical: `/${lang}${path}`,
    languages: {
      ...Object.fromEntries(locales.map((l) => [l, `/${l}${path}`])),
      "x-default": `/${defaultLocale}${path}`,
    },
  };
}

// app/[lang]/about/page.tsx
export async function generateMetadata({ params }: PageProps<"/[lang]/about">): Promise<Metadata> {
  const { lang } = await params;
  return { alternates: localeAlternates(lang as Locale, "/about") };
}
```

## Rules

- **Per page, never in the `[lang]` layout.** Layout metadata is inherited, so a layout canonical of `/${lang}` makes every page a duplicate of the locale home page.
- **Reciprocal.** Every locale version lists every other version, and itself. If one direction is missing, Google ignores the set.
- **`x-default`** names the fallback for unsupported languages.
- Each locale canonicalizes to itself, not to the default locale.
- Use valid codes: `en`, `ar`, `en-GB`, `pt-BR`. Not `uk` for the UK (`uk` is Ukrainian).
- Set `<html lang={lang} dir={dir}>` in the `[lang]` layout. Set `openGraph.locale` per locale (`ar_EG`, `en_US`).
- The language switcher is real `<a href hrefLang>` links that keep the same page (`/en/about` → `/ar/about`), not a `<select>` with `router.push`.
- Don't auto-redirect crawlers based on `Accept-Language` in a way that hides locales. Each locale URL must be fetchable directly.
- Translate the metadata (title, description, OG image text) too, not only the body.

## Sitemap alternates

```ts
// app/sitemap.ts
const entries = pages.flatMap((path) =>
  locales.map((lang) => ({
    url: `${site.url}/${lang}${path}`,
    alternates: {
      languages: Object.fromEntries(locales.map((l) => [l, `${site.url}/${l}${path}`])),
    },
  })),
);
```

## next-intl

Its middleware sends hreflang as a `Link` HTTP header by default (`alternateLinks`). Most SEO tools check `<link rel="alternate">` in the HTML, so keep a `localeAlternates`-style helper in `generateMetadata` as well.
